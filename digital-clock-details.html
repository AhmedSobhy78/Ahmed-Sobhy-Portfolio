DIGITAL CLOCK

ATmega32 & 7-Segment Display Project
University Project

A digital clock system built using an ATmega32 microcontroller with six 7-segment displays (two for hours, two for minutes, two for seconds). The system tracks real time with accurate second-by-second updates and supports features like pause, reset, and time adjustment using push buttons.

Designed and simulated in Proteus, the project demonstrates embedded systems concepts including timer/counter interfacing, multiplexed display control, and button debouncing.
